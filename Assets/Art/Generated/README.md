# Generated Prototype Art

These assets are generated prototype resources for the first garden test level.

They are safe to use as temporary Unity assets, but they are not final production art.

## Folders

- `Hero`: original cup-like heroine sprite atlas and split animation frames.
- `Level01_Garden`: garden background, tile sheet, and split tile sprites.

## Unity Usage

Use the split hero frames for Animator clips:
- `idle`
- `run`
- `jump`
- `dash`
- `shoot`

Use the split tile PNG files to create a Unity Tile Palette for ground and decoration painting.

Use `garden_background_wide.png` as a non-colliding background SpriteRenderer.
