# Codex Agent 调用说明

本目录是当前 Unity 项目的三个独立 Agent 入口。Codex 读取仓库根目录 `AGENTS.md` 后，根据用户请求加载对应角色文件。

## 直接调用

可以在任务中明确指定：

```text
请以产品经理 Agent 工作：确定本版本目标、优先级和验收标准。
请以策划专家 Agent 工作：设计 Boss 阶段、关卡规则、资源规格和数值表。
请以开发专家 Agent 工作：按照已确认设计实现 Unity 代码、资源接入和测试。
```

也可以只描述需求，由 Codex 按 `AGENT_MANIFEST.json` 自动路由：

- 方向、范围、竞品差异、排期和验收 -> 产品经理
- 玩法、UI、角色资源、Boss 规则、关卡、地图和数值 -> 策划专家
- C#、Unity 场景、Prefab、状态机、对象池、碰撞、特效和测试 -> 开发专家
- 跨职责需求 -> 产品经理先拆分，再按顺序调用策划专家和开发专家

## 每次调用的最小上下文

```text
任务目标：
当前版本：
已有依据：
允许修改范围：
验收标准：
相关任务编号：
```

## 调用约束

- 同一时间只让一个 Agent 修改共享工作区。
- 角色切换必须读取新角色文件，不继承上一角色的越权职责。
- 每次交付都要更新任务板和交接报告。
- 产品经理完成最终验收后，才允许提交和推送。
