# DESIGN-005：三形态、打击反馈与界面规格

依据 PM-007。以下参数为 V0.2 首轮可测试起点，不代表已实现或已经平衡验证。所有世界长度以 Unity 单位计，时间以秒计；16×9 舞台、PPU 和当前角色基础移动参数沿用。

## 1. 战斗与接触规则

### 危险物接触矩阵

| 接触情况 | 主角扣血 | 危险物回收 | 能量/反馈 |
| --- | --- | --- | --- |
| 正常状态接触普通一次性弹 | 接受伤害后扣血 | 接受伤害后回收一次 | 受击事件 |
| L/Shift 闪避中接触普通或粉色弹 | 否 | 否，继续原速度和剩余寿命 | 仅闪避烟雾，不播放击破/采集 |
| 3 秒受击无敌中接触普通弹 | 否 | 否 | 不再次播受击音、不重复震屏 |
| 空中非闪避接触可反制粉色弹 | 否 | 反制成功后回收一次 | 能量 +1，反弹与专用反馈 |
| 地面接触粉色弹 | 按普通伤害规则 | 仅接受伤害时回收 | 不给能量 |
| 玩家子弹命中粉色弹 | 否 | 有效射击采集后回收一次 | 能量 +1，轻采集反馈；无角色反弹 |
| 无敌中接触持久危险区 | 否 | 否 | 危险区保留至自身结束 |
| 可受伤时处于持久危险区 | 接受伤害后扣血 | 否 | 由受击无敌与目标伤害间隔保护 |
| 阶段退场、结束战斗、生命周期到期 | 不触发伤害 | 按明确清理原因回收 | 不触发采集或击破奖励 |

受击无敌不禁止主动粉色反制；闪避、大招演出、死亡和战斗锁定禁止反制。若无敌结束后仍在危险区内，需要重新判断伤害，不能只依赖 OnTriggerEnter。高速普通弹通过角色后不得因为曾接触而被延迟回收。

一次租借的危险物只结算一次破坏/采集。普通射击和反制竞争时首个有效结算生效，后续入口只返回“已处理”；不能重复能量、重复音效或重复回收。碰撞判断发生时记录角色状态，不用稍后的 UI 状态推断是否闪避。

### 粉色反制成功时间线

1. t=0：确认可反制且未消费；锁定该实例结算，记录接触点/方向和玩家 ID，发出 ParrySucceeded。
2. 同一呈现帧：主角切到成功姿态，接触点出现粉色白芯星形闪光；播放清脆反制音；逻辑能量立即 +1 并封顶。
3. t=0 至 0.045：短暂停顿。角色/敌人/子弹的战斗模拟停止；成功闪光、音频尾音和 UI 保持表现。输入边沿缓存，不吞掉停顿中按下的闪避或跳跃。
4. 停顿结束：主角竖直速度设为 7.5，保留水平操控；提供 0.18 秒反制保护，避免同一弹群立即追伤。此保护与 3 秒受击无敌独立合并取最长，不取消已有保护。
5. 反制不刷新二段跳次数。仍有一次空中跳时保留；已用完时仅有本次反弹，不凭空加跳。
6. 0.045 至 0.16：冲击环向外扩散，4–6 个星屑散开；角色成功动作持续约 0.10，不长时间锁方向。
7. 0.08 至 0.30：一枚能量标记飞向 HUD 槽位；到达仅表现，不再次加能量。满能量时仍反弹并显示满槽脉冲，不溢出、不累加存储。

普通射击采集只播放轻碎裂、采集音和能量飞入，不触发反弹、保护或全局停顿。空中反制必须明显强于普通射击采集。

### 反馈层级

| 事件 | 画面 | 停顿起点 | 镜头 | 音频 |
| --- | --- | --- | --- | --- |
| 玩家开枪 | 枪口 0.04 秒小亮点，枪/手局部后坐，不推物理根 | 无 | 无 | 轻短枪声，至少 3 个变化 |
| 普通弹命中 Boss | 接触点定向碎屑，局部闪白约 0.05 | 默认无 | 默认无 | 短命中声；同类音最短间隔 0.06 |
| 主角实际受伤 | 0.10 秒受伤姿态，清楚闪白，接续 3 秒无敌闪烁 | 0.055 | 0.12 秒、强度 0.08 | 受击短音优先，普通枪声短暂降低 4dB |
| 粉色反制 | 星形闪光、环、反弹、能量飞入 | 0.045 | 0.06 秒、强度 0.03 | 清脆高辨识音，能量落槽轻音 |
| 闪避 | 起止两团描边烟雾，角色消失/出现 | 无 | 无 | 短掠过与落点轻爆烟，绝不使用反制音 |
| 大招 | 0.12 秒预备、清晰能量束、命中处强亮点 | 首次有效命中 0.07 | 开始 0.14 秒、强度 0.07 | 蓄力、释放、持续、收束四段 |
| 形态死亡/最终胜利 | 独立退场与舞台土屑，最后一名才放胜利表现 | 0.09 上限 | 0.18 秒、强度 0.10 | 阶段退场短句，最终胜利专用尾奏 |

参数需要试玩调整。普通自动射击不得每颗弹触发全局停顿，否则 6.25 发/秒会制造新的操作卡顿。镜头强度加入“标准/减弱/关闭”设置，减弱模式保留所有必要预警。

## 2. 三形态连续遭遇

### 生命周期与公共规则

`Title → Intro → Fighting(Potato) → Transition → Fighting(Onion) → Transition → Fighting(Carrot) → Victory`。
任何有效战斗中的玩家死亡进入 `PlayerDying → Defeat`。暂停为覆盖状态，记住恢复状态；不能以单个 Boss 的 Died 直接决定最终胜利。

- 首次入场约 1.2 秒：Boss 破土、轮廓清楚、短入场音，最后 0.25 秒显示 GO；完成前玩家不受伤，AI 不攻击。
- 形态转换约 1.3 秒：0–0.45 旧 Boss 退场；0.45–0.7 换形；0.7–1.3 新 Boss 入场。先停止伤害、旧弹、大招伤害体和旧 AI，再解绑 HUD 与事件，最后释放旧实体。
- 地图、主角生命和能量保留；角色水平位置保留并约束在合法范围，竖直位置安全落地，锁输入直到入场完成。阶段间不免费回血。
- 新形态恢复输入后至少 0.6 秒才可发生第一次危险判定。清场不计击破、反制或能量奖励。
- 同一物理步同时发生玩家死亡和 Boss 死亡：以玩家死亡为失败优先，避免回调先后决定结果；整场终态只写一次。
- 阶段间暂停、重新开始、返回标题均可安全取消过渡。任何旧代异步回调不得生成新形态中的旧弹。
- 移除旧土豆 70%/35% 分段在新模式中的推进职责。旧种子/地根/飞虫保留代码，但本版本攻击表不同时启用它们，以免叠加成九阶段。

| --- | --- | --- | --- |

| maxHealth | 100 | 120 | 150 |
| spawnX | 4.7 | 4.7 | 4.7 |
| 可见轮廓高度目标 | 3.2 | 3.6 | 4.0 |
| 可见轮廓最大宽度 | 4.2 | 4.2 | 4.2 |
| 地表以下可见埋入量 | 0.12 | 0.12 | 0.12 |

按 alpha 可见轮廓校准尺寸，不再用完整透明图框推断身体占地。右侧可见边界不超过 X=7.4，顶部不侵入 HUD 安全带。土豆/洋葱/胡萝卜可用不同画布尺寸，但同一角色的全部动作必须统一尺寸和基准脚底；体形中心与嘴/眼睛锚点独立标注。

首轮目标战斗时长约 80–140 秒，仅作为调参目标。现有普通射击理论伤害约 6.25/秒，考虑 50%–65% 输出时间和大招，再用实际击杀记录校准生命，不能仅提高 HP 制造压迫感。

### 土豆：水平节奏

- 吸气预备 0.35；连发 3 颗，间隔 0.18；收招 0.45；下一次攻击间隔 0.65–0.95。
- 按高→中→低顺序发射，中心高度以地表为基准 1.75/0.95/0.35，速度 8.0，伤害 1；嘴部高/中/低姿态必须与发射锚点匹配，不允许图片嘴在中间、弹却从头顶或土里出现。
- 每两轮固定安排一颗中位粉色弹作为教学机会，之后可在有限序列内变化，连续两轮不能完全没有粉色机会。不以纯随机决定新玩家能否学会反制。
- 高位弹允许站立躲避，低位弹可跳跃，中位弹结合跳跃/闪避；测试必须证明基础移动参数存在安全解。
- 吸气时身体轻微压缩、嘴部收紧，发射帧身体回弹，脚底世界参考不移动。普通命中只局部闪白，不把整套攻击动画打断到 hurt。

### 洋葱：空间转移

- 主要招式为泪雨：蓄泪 0.65，泪雨组数 4，组间隔 0.42，擦泪恢复 0.85。
- 每组最多 3 个危险落点，地面标记至少提前 0.55 出现；危险列间留连续宽度至少 1.6 的安全走廊，且从前组安全区以正常移动可达。
- 落点由整个可达战斗范围划分为 8 列，不遗漏边缘作为永久安全区；冻结落点后不能追踪玩家修改预警。
- 眼睛涌泪是释放起点，上方泪云/泪滴必须有可见来由；泪滴落速起点 6.5，落地只保留 0.25 秒飞溅，不生成不可读的长期伤害池。
- 每轮第 2 或第 3 组提供一颗粉色泪滴，落点不能在 Boss 身体内或不可达空间。成功反制与通用粉色规则一致。
- 泪雨结束后擦泪喘息，给玩家稳定输出；不得同时启用土豆地根、飞虫和泪雨。

### 胡萝卜：时机与诱导

- 念力束：眼睛蓄光/锁定 0.55，其中最后 0.20 固定方向并停止跟踪；同方向预警细线转为正式束，危险有效 0.18；眩晕恢复 0.75。
- 念力束伤害带宽初值 0.45、伤害 1。L 的 0.18 秒无敌窗只允许时机正确时躲过；测试中必须覆盖早闪、正确闪与晚闪。光束是定时危险区，穿过无敌角色不能回收整束。
- 追踪弹：最多同时 2 颗，生成间隔 0.45，速度 3.8，转向速度上限 100 度/秒，生命周期 4 秒；能被玩家射击销毁。
- 追踪弹发射时标识目标方向，前 0.25 秒仅直飞，之后有限转向；不能贴身生成或无限拐弯粘住主角。
- 第 2 颗允许为粉色版本，采用统一反制规则。念力束与追踪弹首轮交替，验证后才允许追踪弹尾期与下一次预警重叠，危险总量仍受上限限制。
- 眼睛睁大、头顶叶片扬起、地表短促振动与念力低音建立压迫感；不靠全屏黑幕遮住子弹。

## 3. 音频完整链路

使用 Unity AudioSource 池与 AudioMixer，不增加大型音频中间件。分组 Master、Music、Player、Enemy、Impact、UI；战斗音效用位置轻微声像，pan 限制在 ±0.35，关键预警不能只出现在单侧。

| 事件组 | 必需资源 | 并发/优先级 |
| --- | --- | --- |
| 主角 | shot 3 个变化、jump、double_jump、dash_start/end、hurt、death | 枪声最多 4 声部；hurt/death 高于枪声 |
| 反制/能量 | parry_success 2 个变化、pickup、energy_full | 反制独立高优先级，不能被枪声挤掉 |
| 大招 | charge、release、loop、end | loop 必须在取消、死亡、切阶段和重试时停止 |
| 土豆 | emerge、inhale、spit 2 变化、hit、defeat | 预警优先于命中碎音 |
| 洋葱 | emerge、sob_tell、tear_fall、tear_splash、wipe、defeat | 同组落泪限制 3 声部，避免叠加爆音 |
| 胡萝卜 | emerge、psychic_charge、lock、beam、seeker、stun、defeat | lock/beam 独立高优先级 |
| UI/音乐 | focus、confirm、cancel、start、defeat_stinger、victory_stinger、三形态 BGM | UI 不被战斗暂停静音；BGM 过渡淡变约 0.5 |

- Master 初值 0dB，Music -10dB，Player -6dB，Enemy -4dB，Impact -5dB，UI -8dB，均需耳听混音；不把数值当成最终响度保证。
- 总音效并发上限 24，超过时淘汰低优先级且较旧的声音；枪声 pitch 变化 0.96–1.04，关键预警不随机变调。
- 停顿不掐断命中声音；手动暂停停止战斗声源进度、保留 UI 音。音乐暂停/恢复采用平滑过渡，不能重头播放。
- 短音效建议单声道 48kHz 原始 WAV，BGM 立体声并流式加载；导入压缩与响度须在目标构建检查。
- 资源路径：`Assets/Res/Audio/Player`、`Bosses/Potato|Onion|Carrot`、`Combat`、`UI`、`Music`；目录清单登记来源与用途。不得用参考游戏录音当正式素材。

## 4. 资源制作与视觉规则

| 资源集 | 要求 |
| --- | --- |
| Hero | 新增 parry_success、hurt 与专用死亡姿态；统一现有脚底参考与身体旋转中心，禁止叠加两帧冒充中间姿态 |
| Potato | emerge/idle/spit_high/spit_mid/spit_low/recover/defeat；嘴部关键点逐姿态标注 |
| Onion | emerge/idle/cry_tell/cry_loop/wipe/hurt/defeat；两个眼睛发射锚点 |
| Carrot | emerge/idle/charge/lock/beam/seeker/stun/hurt/defeat；眼睛/叶片特效锚点 |
| VFX | Muzzle、BulletImpact、HeroHurt、ParryStar、ParryRing、EnergyTrail、TearSplash、PsychicTell、PsychicBeam、BossEmergence |
| UI | 标题字、开始按钮状态、HUD 生命卡/能量卡、阶段标记、胜败题字、纸张边框/舞台幕布 |

角色资产分别放 `Assets/Res/Hero/Frames` 和 `Assets/Res/Bosses/<Id>/Frames`；特效每种独立 Textures/Materials/Prefabs 放 `Assets/Res/VFX/<Effect>`。按资产实际姿态数量确定帧数和关键帧时间，不规定所有动作固定 9 帧。

危险判定从预警结束后才开启。烟雾必须在子弹后方或较低透明度层，不能掩盖即将碰撞的危险；成功环、预警线与普通碎屑使用不同轮廓，不能只靠颜色区分。

## 5. 开始与结算 UI

### 开始界面

- 使用现有花园舞台作为全幅背景，右侧出现本关三形态的原创轮廓/演出，左侧为工作关卡名“菜园恶战”和开始挑战、设置、退出。
- 主菜单不放倒计时和受伤判定。开始后 0.25 秒淡出菜单，播放入场，再进入可操作战斗；资源未准备完时开始按钮显示忙碌状态并禁止重复启动。
- 键盘上下/WS 选择、Enter 确认、Escape 返回；菜单输入与角色输入分离，按确认不能顺带射击/跳跃。
- 设置至少包含主音量、音乐、音效、镜头震动；保存设置，暂停和标题共用同一配置，不保存临时测试参数。

### 战斗 HUD

- 顶部中央显示当前 Boss 名称、当前生命条和 1/3、2/3、3/3 阶段标记；切形态时先解绑旧血条，再用 0.3 秒填入新形态生命。
- 单独的小进度标记表示整场推进，不把“新 Boss 满血”误读成回血。左下生命与三格能量位置稳定，反制能量飞入以真实 RectTransform 为终点。
- 扣血时对应生命卡翻为灰卡并短暂抖动，不让全部 HUD 持续晃动；Boss 血条延迟血用于明显伤害，大量小命中聚合更新。

### 失败/胜利

- 死亡动作与幽灵演出结束后，约死亡起算 2 秒出现 YOU LOSE；环境压暗、纸质题字/画框进场、失败短音。不能只把当前矩形面板换颜色。
- 失败显示“到达的形态”和整体进度轨迹，主要操作为重新挑战，次要操作为返回标题；详情再展示时间、受伤次数、反制次数，避免大段统计抢走重试按钮。
- 整体进度 = (已击败形态的最大生命之和 + 当前形态已扣生命) / 三形态总最大生命；失败时冻结快照。
- 最终胜利使用独立题字/音色与收尾镜头，不能复用失败底板只换文字。重试从土豆开始；返回标题完全停止战斗音效、清理危险物和事件订阅。
- 1280×720、1920×1080、1024×768 必须保持同一 16:9 安全区；黑边不能包含 HUD。键盘焦点进入结算时默认选中重新挑战，过渡过程中禁止双击重入。

## 6. 配置契约

扩展现有 GameConfig.json，新增 `encounter.forms[]`、`feedback`、`audio`、`presentation` 段；旧 boss 配置只作迁移兼容，不允许同时驱动新遭遇。美术/音频通过目录中的序列化引用纳入构建，JSON 只引用稳定资源 ID。

`forms[]` 至少包含 id、maxHealth、spawnX、embedDepth、visibleHeight、attackSetId、introDuration、recoveryDuration。各攻击表包含 tellDuration、lockDuration、activeDuration、recoveryDuration、shotInterval、speed、damage、maxAlive、pinkPattern、poolKey。音频表包含 eventId、clipIds、mixerGroup、gainDb、priority、maxVoices、minInterval、pitchRange。

Normalize 必须检查非负时间、合法形态顺序、唯一 ID、非空攻击集、可达安全窗口、声部上限；缺关键资源时阻止开始并给中文可定位错误，不能在战斗中静默忽略。所有 UI 文案、颜色主题和动画参数由专用配置/资源驱动，避免继续塞入 GameManager。
