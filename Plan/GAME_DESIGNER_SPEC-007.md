# DESIGN-007 统一美术、Boss演出与视听规格草案

2026-09-14；策划交接方向，由PM-009统筹。用户已明确统一画风与高质量目标；具体资源效果稿尚待验收。

## 统一资源标准

- 基准为手绘橡皮管动画：有机外轮廓、相同线条粗细与抗锯齿、圆润体积、可读五官、同一光照方向。水彩背景低对比，角色轮廓与交互粉色突出。精细来自绘制与动作，不靠增加发光和粒子数量。
- 土豆也需重审，不把旧飞土烘焙进身体帧视作模板。土块、烟尘和口水拆独立特效；洋葱需层叠表皮、泪腺和手臂，胡萝卜需有机根形、面部、额眼及一致线条，停用几何占位图。
- 每位Boss的所有动作统一离线画布，按该角色全动作最大范围联合trim，脚底中心固定像素位置；跳动/伸缩为有意绘制，禁止逐帧独立裁切造成漂移。帧数由真实动作决定，不复制补帧。
- 逐帧记录嘴、眼、脚底和身体区域；身体尺寸与飞散特效分离。所有关键姿态必须在实际目标屏幕尺寸查看，不能只验原图大图。
- 目录：Assets/Res/Bosses/{Potato,Onion,Carrot}/{Frames,Prefabs,Data}；Assets/Res/VFX/{Muzzle,Hit,Parry,Hurt,Dodge,PotatoEmerge,OnionLand,CarrotEnter,Super}；音频沿用Assets/Res/Audio的Catalog分组。参考清单记录来源、原始文件、动作、处理版本、验收状态。

## 三种入场

| Boss | 演出顺序 | 候选时长与声音 |
| --- | --- | --- |
| 土豆 | 地面鼓起、裂土、双手撑地、头身上升、落稳进入待机；土沿遮住下部，禁止根节点纵向展开 | 1.2至1.6秒；低频土响、碎土、撑起、落稳短重音 |
| 洋葱 | 右侧落点影子/尘点先提示，身体从画面上方落下，落地挤压由真实帧表现，回弹后站稳 | 0.9至1.3秒；下坠呼声、钝落地、余震尘土 |
| 胡萝卜 | 暂定四周念力波纹和半透明分身汇聚，右侧唯一实体显现、额眼点亮、进入待机；分身不碰撞不伤害 | 1.2至1.6秒；四周轻声像、念力渐强、显形短重音 |

入场/退场独立，不复用同一个缩放器。只有站稳/显形完成才开放Boss攻击与受伤；入场角色不可误伤玩家。入场特效可越过边界，Fighting状态身体必须在安全画幅内；入场时长不等于固定截断动画。

产品暂定沿用当前过场玩家锁定，不在本轮同时修改移动权限；策划提出“过场可移动”作为后续候选。入场完成后保留至少0.6秒安全窗口再进入首招预备，不能省略现有保护。

## 土豆吐弹样板

每发使用真实的吸气/嘴部准备、开口释放、收嘴回弹；首发额外蓄力，随后三次释放互不跳帧。保留高/中/低横向弹道，每路必须有对应嘴位姿态，不能在同一嘴图上强设三个弹体高度。

用一张时序表定义动作帧、持续时间、嘴部锚点、release标记与声音事件。0.18秒间隔先作为旧参数，不硬性保留；建议先测0.22至0.28秒的清晰动作窗口，再结合躲避难度校准。实际候选数值须在资源到位后锁定。

同一release事件当帧：切到张嘴关键帧、从该帧嘴坐标生成弹体、口部短闪/口水或细土粒、吐气声。普通命中事件：接触点星形墨线爆花、少量定向碎屑、短局部闪白、柔韧撞击声；不要每颗子弹都全局停顿/震屏。

## UI返工

- HUD保留顶部中央Boss血条、左下生命牌/能量牌；边框改手绘单一墨线，牌面明确红心/能量符号，减少细装饰和重复框。血条延迟追齐保留，主体数据不延迟。
- 标题采用一张统一风格的完整角色构图及独立题字，三项菜单用清晰排版与手套/箭头焦点，不再拼几何角色画像与宽票券按钮。
- 失败用暗下来的战斗背景、醒目YOU LOSE题字、主角死亡插画、清晰阶段进度和重试焦点；胜利有独立庆祝构图，不只改文字颜色。
- 结算背景定格在确切的被击败/退场状态，不能让Boss继续呈现完好待机；浅背景上的胜利题字需有足够明暗对比。
- 暂停/设置采用相同字体、墨线和焦点符号。正文优先可读，不能为了复古让中文细碎。最终1280×720、1920×1080、1024×768有效画幅均需实机检查。

## 特效与声音事件矩阵

| 事件 | 视觉与体感 | 声音 |
| --- | --- | --- |
| 普通命中 | 小而有方向的爆花，短闪白；不全局停顿 | 3至5种轻撞击，控制连射叠音 |
| 粉弹反制 | 接触点清晰粉白星爆、弹体碎裂、角色反弹、能量飞入；保留短顿帧 | 清脆反制音、短上扬尾音；不能被枪声覆盖 |
| 玩家受伤 | 单次明确受伤姿态、闪白/短抖动，再显示无敌闪烁；保证3秒保护 | 受伤主重音，短时压低枪声/音乐但不盖住后续预警 |
| 闪避 | 起点与终点独立云团，方向性颗粒；主体仍清楚，烟雾不挡来弹 | 起步短噗、结束轻呼气；不重复扣弹 |
| 大招 | 蓄力、释放、命中和收束四段；清楚轮廓优先于满屏发光 | 蓄力渐强、发射重音、受控循环、停止尾音 |
| Boss被击败 | 专属踉跄/溃散/退场，停止旧攻击，交接下一形态 | 击败重音、尾声、下一形态过门 |

BGM采用同一主旋律/和声语言，土豆弹跳木管与节奏，洋葱较稀疏的泪雨段，胡萝卜更强铜管与切分。保留现有三阶段编曲作比较基线，听后决定替换，不能仅凭代码判定已好听。无缝循环无爆点，切阶段做短过门或合适交叉淡化。声音资源需分层、区分攻击/命中/反制/受伤，避免全用一种合成音变调。

## 美术和视听门禁

先交付三Boss同屏设定对照、土豆入场和吐弹完整序列、战斗HUD与失败页效果稿；再交付可交互30至60秒土豆样板。看单帧也应属于同一作品，看慢放嘴弹对齐，正常速度能读懂预警。耳机/扬声器、有声/静音都验证关键危险可读；60秒连射不刺耳，音效不削波，音乐不淹没预警。完整录像带声音，截图与测试数量不能替代此门禁。
