# 策划规格 DESIGN-003

## 操作与状态

| 行为 | 输入 | 规则 | 可观察反馈 |
| --- | --- | --- | --- |
| 移动 | A/D 或方向键 | 水平速度直接达到目标速度，松开后快速归零 | run/idle 切换不重置序列帧 |
| 一段跳 | Space | 地面或土块边缘缓冲窗口内起跳 | jump 动作 |
| 二段跳 | 空中再次 Space | 消耗一次空中跳，使用翻滚动作并绕视觉中心旋转 | 360 度翻滚 |
| 冲刺 | L | 冲刺期间无敌，冷却后可再次使用 | 起点和终点烟雾，dash 动作 |
| 射击 | J 或 Z | 按住连发，子弹从角色胸口前方发出 | shoot 动作和子弹 |

## 受击与死亡

- 每次有效受击扣 1 格生命，并进入 3 秒无敌窗口。
- 受击反馈持续短于无敌窗口，包含闪白、命中粒子和镜头抖动，不阻塞输入。
- 生命归零后关闭物理碰撞，先播放一次死亡动作，再变为淡蓝幽灵向上消失。
- 2 秒后显示失败结算；失败阶段清理 Boss 投射物，避免结果界面继续受伤。

## 粉色子弹

- 粉色子弹使用亮粉核心、深色轮廓和较大的碰撞半径。
- 玩家处于空中且与粉色子弹接触时，子弹被击碎，玩家获得 1 格能量，不扣生命。
- 仅当玩家在空中时触发，地面直接接触仍为受击，避免站在子弹上无风险刷能量。
- 能量上限为 3 格，满能量后按 K 释放大招。

## HUD

- Boss 血条固定顶部中央，标题和阶段信息低于血条，主体宽度不超过安全画布。
- 玩家生命位于左下角，以扑克牌卡片表示当前生命，每张卡片有轻微上下浮动和旋转。
- 能量紧邻生命卡右侧，使用三个稳定尺寸的槽位。
- 失败结算使用中央深色半透明面板、强调色标题、统计文本和明确的 `RETRY` 按钮。
