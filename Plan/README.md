# 2D Boss Rush 项目计划

本文件夹用于记录这个 Unity 2D 项目的长期开发计划、每日待开发内容、已完成内容、测试结果和待办事项。

## 项目定位

目标是制作一款受《茶杯头》核心玩法启发的原创 2D 横版 Boss Rush 射击游戏。

重要边界：

- 可以学习高难度横版动作射击、Boss 多阶段、弹幕躲避、弹反和评分等玩法结构。
- 不直接复制《茶杯头》的角色、美术、音乐、关卡、Boss 形象、剧情、商标或具体素材。
- 最小可玩目标是让原创角色挑战一个原创 Boss。

## 文件说明

| 文件 | 用途 |

| `input_policy.md` | 输入设备支持范围和后续扩展规则。 |

## 记录规则

每天开发前：

1. 在 `daily_dev_log.md` 新增当天日期。
2. 写下今天要完成的 1-3 个任务。
3. 优先选择能让游戏更可玩、更可测的任务。

每天开发后：

1. 记录已完成内容。
2. 记录修改过的核心文件。
3. 把测试结果写入 `test_log.md`。
4. 未完成事项移入下一天或 `backlog.md`。

## 语言规范

- 所有开发日志、测试日志和计划说明默认使用中文记录。
- 文件路径、类名、Unity 组件名、命令行命令和资源名保持原文，不强行翻译。
- 如果终端预览出现中文乱码，以 UTF-8 文件内容为准，不代表文件内容损坏。
