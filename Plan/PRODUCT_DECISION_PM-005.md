# 产品决策 PM-005

## 目标

本轮只解决 V0.1 Boss 战的可玩性基础：玩家移动、跳跃、二段跳翻滚、L 冲刺、受击扣血、无敌窗口、粉色子弹反制、Boss 位置、血条、失败结算和重试。

## 取舍

- 暂不加入手柄、音效、音乐、额外关卡和新的复杂 Boss 招式。
- 保留当前三阶段 Boss 逻辑，先修正基础战斗反馈，不扩大玩法范围。
- 受击无敌统一为 3 秒；冲刺和大招继续保持无敌。
- Boss 固定在画面右半区，底部只埋入少量土层；血条固定画面顶部中央。
- 玩家生命采用左下角扑克牌式卡片，能量与生命放在同一 HUD 层级。
- 粉色子弹是可读的高价值反制目标：玩家跳跃接触时击碎并获得 1 格能量，其他接触仍按普通伤害处理。

## 验收标准

- 键盘输入下，玩家松开方向键后立即停止，不出现明显由慢到快或残余滑行。
- 二段跳翻滚围绕角色视觉中心旋转，落地后恢复无旋转状态。
- 受击后 3 秒内重复调用 `TakeDamage` 不扣血；受击有闪白、粒子和镜头抖动。
- L 冲刺全过程不扣血，并在起点和终点生成烟雾。
- Boss 的世界坐标在右半区，血条 UI 的 anchor 为顶部中央。
- 玩家死亡先播放死亡动作和幽灵上升，等待配置的 2 秒后显示 `YOU LOSE`。
- 失败界面按钮可以重新加载当前场景，场景重新开始后生命、Boss、投射物和统计均恢复初始状态。
- 粉色子弹可被玩家空中接触击碎，能量最多增加到 3 格。

## 风险

- 当前资源导入仍由运行时资源目录和编辑器导入配置共同控制；本轮不重做 PNG，只保证运行时锚点层级稳定。
- 本地未必有可用 Unity Editor 进程，若只能执行 C# 项目构建，最终仍需在 Unity Console 和实际窗口补做人工验收。
