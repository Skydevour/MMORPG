## 状态定义

- `待拆分`：产品目标尚未拆成可执行任务。
- `待策划`：等待策划输出规则、资源或数值规格。
- `待开发`：设计已确认，可以进入实现。
- `开发中`：当前 Agent 独占共享工作区。
- `待验收`：已有交付报告，等待产品经理检查。
- `返工`：验收失败，必须附具体问题和重现步骤。
- `已完成`：通过验收并由产品经理提交。
- `阻塞`：缺少决策、资源或外部条件。
