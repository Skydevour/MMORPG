# Cuphead-like 2D Game Design

## 对《茶杯头》主要玩法的理解

《茶杯头》的核心不是传统平台跳跃探索，而是高强度 2D 横版 Boss Rush 动作射击。玩家在较小但压力很高的战斗空间里移动、跳跃、冲刺、持续射击，同时观察 Boss 的动作前摇、弹幕轨迹和阶段变化。胜利通常来自学习招式、稳定执行和资源管理。

核心玩法要点：
- Boss 多阶段：Boss 血量下降后切换形态、攻击节奏、弹幕组合或场地规则。
- 横版射击：玩家可以持续射击，边移动边输出，也可以锁定方向站定射击。
- 弹幕躲避：敌方攻击包含直线弹、扇形弹、追踪弹、地面危险、召唤物和场地机关。
- 弹反机制：特定颜色或标记的目标可以被弹反，成功后通常增加能量并给玩家额外空中控制。
- 低血量高压：玩家容错较低，受伤反馈清晰，失败后快速重开。
- EX 和大招：普通攻击、弹反或战斗行为积累能量，用于强力技能。
- 装备选择：不同武器、护符和超级技能改变战斗策略。
- 评分系统：通关时间、剩余生命、弹反次数、技能使用和难度影响结算评价。

## 基础操作方案

| 操作 | 键盘默认 | 手柄默认 | 说明 |
| --- | --- | --- | --- |
| 左右移动 | A / D | 左摇杆 / 十字键 | 基础横向移动。 |
| 下蹲 | S | 下方向 | 缩小受击区域或躲避特定攻击。 |
| 跳跃 | Space | South Button | 支持短按低跳、长按高跳。 |
| 空中冲刺 | Left Shift | East Button | 横向快速位移，有冷却或单次空中限制。 |
| 射击 | J | West Button | 按住持续射击。 |
| 锁定方向 | K | Right Shoulder | 站定并锁定射击方向。 |
| 瞄准方向 | 方向键 / WASD 组合 | 左摇杆 | 支持水平、垂直、斜向射击。 |
| 弹反 | 空中再次按 Space | South Button | 只对可弹反目标生效。 |
| 切换武器 | Q / E | LB / RB | MVP 可先只做一种武器。 |
| EX 技能 | L | North Button | 消耗 1 格能量。 |
| 暂停 | Esc | Start | 打开暂停菜单。 |

## 复现策略

推荐路线：先做原创垂直切片，再扩内容。

三种可选做法：
- 方案 A：单 Boss 垂直切片。最快验证手感、弹幕、Boss 阶段、失败重开和胜利结算。推荐。
- 方案 B：先做跑枪关卡。更像完整游戏，但会过早牵扯地形、敌人种类、关卡编辑和镜头边界。
- 方案 C：先做世界地图和菜单。展示感强，但核心玩法风险没有被验证，不推荐作为第一阶段。

本项目采用方案 A：
1. 做一个可移动、可跳跃、可冲刺、可射击、可受伤的玩家。
2. 做对象池和子弹系统。
3. 做可弹反目标和能量条。
4. 做一个原创三阶段 Boss。
5. 做死亡重开、胜利结算和评分。
6. 再扩展武器、护符、更多 Boss 和跑枪关卡。

## MVP 验收标准

第一版 Demo 必须满足：
- 玩家可以稳定移动、跳跃、空中冲刺、射击和受伤。
- 子弹、伤害、生命、无敌帧可正常工作。
- 至少有 1 种可弹反目标。
- Boss 有 3 个阶段，每个阶段至少 2 种攻击。
- 玩家死亡后能快速重开。
- Boss 被击败后进入胜利界面。
- 胜利后显示通关时间、剩余生命、弹反次数和评级。

## 美术与版权方向

采用“受复古动画启发的原创手绘风”，不使用《茶杯头》的任何角色、Boss、音乐、字体、关卡和图形资产。

可选原创主题：
- 发条玩具剧场
- 魔法马戏团
- 茶点王国之外的原创餐桌幻想
- 旧电影怪谈
- 纸偶舞台

MVP 阶段使用简单几何图形或占位贴图，先验证手感和战斗循环。
